## 一、产品介绍

### 1. 概述
ESS57C 总线型步进电机驱动系统是在传统数字闭环步进驱动器基础上集成了高可靠性 CAN 现场总线通讯接口及内置单轴运动控制器。总线通讯遵循国际 CAN-in-Automation（CiA）标准协议，完整支持 **CiA 301 通讯子协议** 以及面向运动控制的 **CiA 402 设备子协议**。相比传统脉冲控制方式，总线型驱动器通过一根屏蔽双绞线即可实现远距离可靠控制，彻底杜绝工业强电磁干扰环境下由于脉冲丢失导致的加工误差与废品率；同时支持上位机实时读取驱动器运行状态、电流、实际位置与故障代码。

### 2. 特点
* **标准总线架构**：采用 CAN 总线通讯，完整遵循 CANopen CiA 301 与 CiA 402 子协议，单网段最多可挂载 32 台从站设备；
* **远距离抗干扰**：总线指令传输取代传统脉冲信号，彻底消除远距离脉冲信号衰减与干扰丢步问题；
* **在线状态监控**：支持上位机在线实时修改运行电流、电子细分，实时查询电机当前位置、速度及报警状态；
* **内置单轴控制器**：内部集成硬件运动控制器，只需设置目标位置、速度、加减速度即可自主生成梯形/S型加减速轨迹，实现精准的位置模式（PP）、速度模式（PV）和回原点（HM）控制；
* **可编程通用 IO**：
  - 4 路光电隔离可编程输入接口（X0 ~ X3），用于驱动器使能、启停、急停、限位及原点信号；
  - 2 路光电隔离可编程输出接口（Y0 ~ Y1），用于报警指示、到位反馈、抱闸控制及用户自定义状态；
* **完善防护功能**：具有母线过压、欠压、过流、相间短路、位置超差等实时保护。

### 3. 典型应用
适合各种中小型自动化设备和仪器，例如：工业机器人、半导体搬运设备、特种工业缝纫机、线束剥线机、激光雕刻切割机、数控机床、自动化装配流水线、医疗分析仪器等。在期望抗干扰、高速度、多轴总线同步的设备中效果最佳。

  - **红灯连续闪烁 5 次**：位置误差超差报警（0xFF05）（⚠️注意：ESS57C 超差为闪烁 5 次！）。

## 四、拨码开关设定（SW1 ~ SW5）

ESS57C 采用 5 位 DIP 开关设定从站节点地址（Node-ID）、总线波特率及终端匹配电阻：
- **SW1 ~ SW3**：设定 CANopen 从站硬件 Node-ID（1 ~ 7）；
- **SW4**：设定 CAN 通信波特率（125K / 500K）；
- **SW5**：CAN 总线内置 120Ω 终端电阻使能开关。

### 1. 从站站号设定表（SW1 ~ SW3）
| 从站号 (Node-ID) | SW1 | SW2 | SW3 | 设定说明 |
| :---: | :---: | :---: | :---: | :--- |
| **default** | ON | ON | ON | 默认档：通过对象字典 `0x2030` 自定义从站地址（范围 1 ~ 127） |
| **1** | OFF | ON | ON | 硬件固定 Node-ID = 1 |
| **2** | ON | OFF | ON | 硬件固定 Node-ID = 2 |
| **3** | OFF | OFF | ON | 硬件固定 Node-ID = 3 |
| **4** | ON | ON | OFF | 硬件固定 Node-ID = 4 |
| **5** | OFF | ON | OFF | 硬件固定 Node-ID = 5 |
| **6** | ON | OFF | OFF | 硬件固定 Node-ID = 6 |
| **7** | OFF | OFF | OFF | 硬件固定 Node-ID = 7 |

### 2. 通信波特率设定（SW4）
| 通讯波特率 | SW4 状态 | 应用推荐距离 |
| :---: | :---: | :--- |
| **125 kbps** | **ON** | 原手册仅标注 SW4=ON 为 125K |
| **500 kbps** | **OFF** | 原手册仅标注 SW4=OFF 为 500K |

> **提示**：从站号与波特率修改后，必须重新断电上电才能生效。

### 3. CAN 终端匹配电阻（SW5）
- **总线末端驱动器**：将 **SW5 拨至 ON**（接入内置 120Ω 差分终端电阻）；
- **链路其余驱动器**：将 **SW5 拨至 OFF**。

## 五、CANopen 通讯协议与对象字典（Object Dictionary）

### 1. SDO 通信机制与报文格式
SDO 基于客户端/服务器模式，用于对从站对象字典的读写访问：
- **SDO 的 COB-ID 分配**：
  - **Rx-SDO（主站发送至从站）**：`0x600 + Node-ID`（范围 601h ~ 67Fh）；
  - **Tx-SDO（从站应答至主站）**：`0x580 + Node-ID`（范围 581h ~ 5FFh）。
- **SDO 读报文命令字**：
  - 主站读请求命令字：`0x40`；
  - 从站正常应答命令字：`0x4F` (1字节), `0x4B` (2字节), `0x47` (3字节), `0x43` (4字节)；错误应答：`0x80`。
- **SDO 写报文命令字**：
  - 主站写请求命令字：`0x2F` (1字节), `0x2B` (2字节), `0x27` (3字节), `0x23` (4字节)；
  - 从站写成功应答命令字：`0x60`；写失败应答：`0x80`。

### 2. PDO 映射与通信机制
PDO 用于实时周期性高速数据交换：
- **RPDO1 ~ RPDO4（主站控制从站）**：
  - RPDO1: COB-ID `0x200 + Node-ID` (通信参数 1400h，默认映射 6040h 控制字、60FFh 速度、6060h 模式)；
  - RPDO2: COB-ID `0x300 + Node-ID` (通信参数 1401h，默认映射 607Ah 目标位置、6081h 目标速度)；
  - RPDO3: COB-ID `0x400 + Node-ID` (通信参数 1402h，默认映射 6083h 加速度、6084h 减速度)；
  - RPDO4: COB-ID `0x500 + Node-ID` (通信参数 1403h)。
- **TPDO1 ~ TPDO4（从站状态上报）**：
  - TPDO1: COB-ID `0x180 + Node-ID` (通信参数 1800h，默认映射 6041h 状态字、6061h 实际模式)；
  - TPDO2: COB-ID `0x280 + Node-ID` (通信参数 1801h，默认映射 6064h 实际位置、606Ch 实际速度)；
  - TPDO3: COB-ID `0x380 + Node-ID` (通信参数 1802h)；
  - TPDO4: COB-ID `0x480 + Node-ID` (通信参数 1803h)。

### 3. CiA 402 状态机跳转与控制字/状态字对照

```text

               │ Not Ready to Switch On│
               └──────────┬────────────┘

         │     └──────────┬────────────┘
         │ 7              │ 2
         │                ▼
         │     ┌───────────────────────┐
         ├─────┤    Ready to Switch On │◄────┐
         │ 6   └──────────┬────────────┘     │
         │                │ 3                │
         │                ▼                  │
         │     ┌───────────────────────┐     │
         ├─────┤      Switched On      ├─────┤
         │ 5   └──────────┬────────────┘ 8   │
         │                │ 4                │
         │                ▼                  │
         │     ┌───────────────────────┐     │
         └─────┤    Operation Enable   ├─────┘

                          │ 11
                          ▼
               ┌───────────────────────┐
               │   Quick Stop Active   │
               └───────────────────────┘
```

#### 控制字（6040h）切换状态指令表
| 目标状态转换 | 控制字写指令（Hex） | 位定义变化要求 | 状态转换路径 |
| :--- | :---: | :--- | :---: |
| **Shutdown** | `0x0006` | Bit7=0, Bit2=1, Bit1=1, Bit0=0 | 2, 6, 8 |
| **Switch On** | `0x0007` | Bit7=0, Bit2=1, Bit1=1, Bit0=1 | 3 |
| **Enable Operation (使能)** | `0x000F` | Bit7=0, Bit3=1, Bit2=1, Bit1=1, Bit0=1 | 4, 16 |
| **Disable Voltage** | `0x0000` | Bit1=0 | 7, 9, 10, 12 |
| **Quick Stop (急停)** | `0x0002` (或 0x000B) | Bit2=0, Bit1=1 | 7, 10, 11 |
| **Disable Operation** | `0x0007` | Bit3=0, Bit2=1, Bit1=1, Bit0=1 | 5 |
| **Fault Reset (故障复位)** | `0x0080` (0->1 上升沿) | Bit7 上升沿 | 15 |

| Bit6 | Bit5 | Bit3 | Bit2 | Bit1 | Bit0 | 对应驱动器当前状态 |
| :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| 0 | X | 0 | 0 | 0 | 0 | **Not ready to switch on**（未准备好） |
| 1 | X | 0 | 0 | 0 | 0 | **Switch on disabled**（禁止合闸） |
| 0 | 1 | 0 | 0 | 0 | 1 | **Ready to switch on**（准备好合闸） |
| 0 | 1 | 0 | 0 | 1 | 1 | **Switched on**（已合闸，未使能） |
| 0 | 1 | 0 | 1 | 1 | 1 | **Operation enabled**（使能正常运行中） |
| 0 | 0 | 0 | 1 | 1 | 1 | **Quick stop active**（快速急停中） |
| 0 | X | 1 | 1 | 1 | 1 | **Fault reaction active**（故障响应激活） |
| 0 | X | 1 | 0 | 0 | 0 | **Fault**（驱动器故障锁定） |

## 七、PLC 标准运动控制功能块编程指南（Motion Control Blocks）

用户在 PLC（如汇川 H5U、西门子、倍福等）上编写标准 CANopen CiA 402 运动控制程序时，核心功能块执行步骤如下：

### 1. MC_POWER（驱动器使能）
* **功能描述**：驱动器状态机合闸并使能电机得电。
* **执行步骤**：
  1. 写入 `6040h = 0x0000`，等待 `6041h.bit0~bit3 = 0x0000`（进入 Switch on disabled 释放状态）；
  2. 写入 `6040h = 0x0006`，等待 `6041h.bit0~bit3 = 0x0001`（进入 Ready to switch on 状态）；
  3. 写入 `6040h = 0x0007`，等待 `6041h.bit0~bit3 = 0x0003`（进入 Switched on 状态）；
  4. 写入 `6040h = 0x000F`，等待 `6041h.bit0~bit3 = 0x0007`（进入 Operation enabled 使能正常工作状态，电机锁轴）。

### 2. MC_RESET（故障复位）
* **功能描述**：清除驱动器当前报警锁定状态。
* **执行步骤**：
  1. 写入 `6040h.bit7 = 0`（复位准备）；
  2. 写入 `6040h.bit7 = 1`（向 Bit7 写入上升沿脉冲，驱动器清除故障并跳转至 Switch on disabled）。

### 3. MC_STOP（停止命令）
* **功能描述**：使正在运动中的轴减速停机。
* **执行步骤**：
  1. 写入 `6040h.bit8 = 0`（停止准备）；
  2. 写入 `6040h.bit8 = 1`，将 `60FFh = 0`，电机减速停机；
  3. 监控 `606Ch (实际速度) = 0`，停止完成。

### 4. MC_HOME（回原点命令）
* **功能描述**：执行硬件回零算法，支持 4 种原点模式（对象字典 `6098h`）。
* **四大回零模式详细动作规则**：
  1. **负限位模式（回零模式 17）**：反向寻找原点（负限位），减速点为负限位，原点判定为**负限位下降沿**。
     - 负限位开关为无效时，以反向高速（`6099h-01`）开始回零；遇到负限位开关为有效时（沿变化），减速、反向，正向低速（`6099h-02`）运行，遇到负限位开关无效时（沿变化）立即停止。
     - 负限位开关为有效时，直接正向低速开始回零，遇到负限位开关为无效时（沿变化）立即停止。
  2. **正限位模式（回零模式 18）**：正向寻找原点（正限位），减速点为正限位，原点判定为**正限位下降沿**。
     - 正限位开关为无效时，以正向高速（`6099h-01`）开始回零；遇到正限位开关为有效时（沿变化），减速、反向，反向低速（`6099h-02`）运行，遇到正限位开关无效时（沿变化）立即停止。
     - 正限位开关为有效时，直接反向低速开始回零，遇到正限位开关为无效时（沿变化）立即停止。
  3. **正向原点模式（回零模式 24）**：正向寻找原点（原点开关），减速点为原点开关，原点判定为**原点开关上升沿**。
     - 原点开关为无效且未遇到正限位开关时：以正向高速开始回零，遇到原点开关为有效时（沿变化），减速、反向，反向低速运行，遇到原点开关无效时（沿变化），反向，正向低速运行，遇到原点开关有效时（沿变化）停止；
     - 原点开关为无效且先遇到正限位开关时：正向高速开始回零，遇到正限位开关自动反向高速运行，遇到原点开关有效时（沿变化），减速、反向低速运行，遇到原点开关无效时（沿变化），反向，正向低速运行，遇到原点开关有效时（沿变化）停止；
     - 原点开关为有效时：直接反向低速开始回零，遇到原点开关为无效时（沿变化），反向，正向低速运行，遇到原点开关为有效时（沿变化）停止。
  4. **反向原点模式（回零模式 29）**：反向寻找原点（原点开关），减速点为原点开关，原点判定为**原点开关上升沿**。
     - 原点开关为无效且未遇到负限位开关时：以反向高速开始回零，遇到原点开关为有效时（沿变化），减速、反向低速运行，遇到原点开关无效时（沿变化），反向，正向低速运行，遇到原点开关有效时（沿变化）停止；
     - 原点开关为无效且先遇到负限位开关时：反向高速开始回零，遇到负限位开关自动反向正向高速运行，遇到原点开关有效时（沿变化），减速、反向低速运行，遇到原点开关无效时（沿变化），反向，正向低速运行，遇到原点开关有效时（沿变化）停止；
     - 原点开关为有效时：直接反向低速开始回零，遇到原点开关为无效时（沿变化），反向，正向低速运行，遇到原点开关为有效时（沿变化）停止。
* **执行步骤**：
  1. 模式切换：写入 `6060h = 6`，监控 `6061h = 6`（确认进入回零模式）；
  2. 使能电机：控制字 `6040h` 依次写入 `0x06`、`0x07`、`0x0F`（间隔约 10ms），电机使能；
  3. 设置回零参数：设置 `6098h`（回零方式 17/18/24/29）、`6099h-01`（快速）、`6099h-02`（慢速）、`609Ah`（加减速）、`607Ch`（原点偏移量）；
  4. 触发回零：写入 `6040h.bit4 = 0` 准备，随后写入 `6040h.bit4 = 1` 启动回零；
  5. 结果监控：
     - 若 `6041h.bit10 = 1` 且 `6041h.bit12 = 1`：**回原点成功**；
     - 若 `6041h.bit10 = 1` 且 `6041h.bit13 = 1`：**回原点失败**。

### 5. MC_MOVABS（绝对定位命令）
* **功能描述**：按绝对坐标运行至目标位置。
* **执行步骤**：
  1. 模式切换：写入 `6060h = 1`，监控 `6061h = 1`（进入位置模式）；
  2. 写入运动参数：`607Ah`（目标位置）、`6081h`（速度）、`6083h`（加速度）、`6084h`（减速度）；
  3. 准备触发：写入 `6040h = 0x000F`，等待 `6041h.bit12 = 0`；
  4. 上升沿触发：写入 `6040h = 0x001F`（Bit4 置 1 启动绝对定位）；
  5. 监控到位：等待 `6041h.bit10 = 1` 且 `6041h.bit12 = 0`（或 `6064h == 607Ah`），到位完成。

### 6. MC_MOVREL（相对定位命令）
* **功能描述**：按相对当前位置增量位移运行。
* **执行步骤**：
  1. 模式确认：`6060h = 1`；
  2. 写入相对脉冲参数至 `607Ah`、速度加减速度；
  3. 准备触发：写入 `6040h = 0x004F`（Bit6 置 1 表示相对位置）；
  4. 启动触发：写入 `6040h = 0x005F`（Bit4 置 1 触发相对定位）；
  5. 到位确认：监控 `6041h.bit10 = 1` 到位。

### 7. MC_MOVVEL / MC_JOG（速度与点动运行命令）
* **功能描述**：连续速度运转与手动 JOG 点动。
* **执行步骤**：
  1. 模式切换：写入 `6060h = 3`，监控 `6061h = 3`（进入速度模式）；
  2. 设置加减速与目标速度 `60FFh`（正数正向，负数反向）；
  3. 启动速度运行：写入 `6040h = 0x000F`（Bit8 Halt=0）；
  4. 停止运行：写入 `60FFh = 0` 或设置 `6040h.bit8 = 1`（Halt 停止）。
