# ESS57P 一体化数字式混合伺服 使用说明书

> **常州市金三士机电有限公司**

## 一、产品介绍

### 1. 概述
ESS57P 是一款新型带通讯功能的电机驱动一体化混合伺服驱动系统。采用先进的 32 位高性能 ARM 芯片和闭环控制技术，可以防止失步，保证产品的精度；高速转矩衰减远低于传统开环驱动器，可以大幅提升步进电机的高速性能和力矩；采用基于负载的电流控制技术，有效减低电机温升，延长电机使用寿命；内置报警输出信号，方便上位机进行监测和控制；位置超差报警功能保证了加工设备的安全运行。是传统开环步进驱动的理想升级换代产品，并且可以替代部分传统交流伺服系统，价格仅为交流伺服系统的 50%。

### 2. 特点
* **先进闭环**：采用先进的 32 位高性能 ARM 芯片以及闭环控制技术；
* **工作不失步**：默认工作在闭环模式，彻底杜绝丢步失步；
* **力矩提升**：显著提高电机的输出力矩及高速运行速度；
* **智能电流**：电流大小根据负载智能调节，降低电机温升，锁机电流与闭环峰值电流可调；
* **自适应负载**：适应各种机械负载状况（包括低刚性的皮带轮和滑轮等负载），不需要现场调整增益参数；
* **零速静止**：完成定位之后，具备无振动的零速静止能力；
* **脉冲接口**：支持单脉冲（脉冲+方向）与双脉冲（CW/CCW）输入，脉冲响应频率最高可达 200kHz；
* **固定细分**：支持 16 种固定细分数；
* **供电宽压**：供电电压范围 DC +24V ~ 48V（推荐供电 DC +36V）；
* **原生宽压 IO**：控制信号端口原生**支持 5 ~ 24V 信号电平，无需外部串接限流电阻**；
* **保护完善**：具有过流、过压、位置超差等实时保护。

### 3. 典型应用
适合各种中小型自动化设备和仪器，例如：工业机器人、纺织机械、特种工业缝纫机、剥线机、打标机、切割机、激光照排、绘图仪、数控机床、雕刻机、自动装配设备等。在用户期望低噪音、高速度的设备中应用效果特佳。

## 三、驱动器接口与接线介绍

### 1. 接口详细定义

#### (1) 电源输入口（2Pin 绿色端子）
| 端子号 | 符号 | 名称 | 详细说明 |
| :---: | :---: | :---: | :--- |
| **1** | **+Vdc** | 直流电源正端 | DC +24V ~ 48V（推荐供电 DC +36V） |
| **2** | **GND** | 直流电源地 | 直流电源负极参考地 |

#### (2) 控制信号端口（8Pin 黑色插座）
| 端子号 | 符号 | 名称 | 详细功能说明 |
| :---: | :---: | :---: | :--- |
| **1** | **PU+** | 脉冲正输入 | **支持 5 ~ 24V 宽电平输入，无需外接电阻** |
| **2** | **PU-** | 脉冲负输入 | 脉冲输入负端 |
| **3** | **DR+** | 方向正输入 | **支持 5 ~ 24V 宽电平输入，无需外接电阻** |
| **4** | **DR-** | 方向负输入 | 方向输入负端 |
| **5** | **EN+** | 使能正输入 | **支持 5 ~ 24V 宽电平输入，无需外接电阻** |
| **6** | **EN-** | 使能负输入 | 使能输入负端，默认断开为使能状态 |
| **8** | **AL+** | 报警信号正输出 | 光电隔离 OC 门输出，默认闭合指示有报警，开路指示无报警 |
| **9** | **AL-** | 报警信号负输出 | 报警信号负端，最高承受电压 30VDC，最大饱和电流 50mA |

#### (3) 状态指示灯（LED）
- **PWR（绿灯）**：电源指示灯。通电正常时常亮。
- **ALM（红灯）**：故障报警指示灯。在 3 秒周期内连续闪烁次数代表故障类型：
  - **红灯闪烁 1 次**：过流或相间短路故障；
  - **红灯连续闪烁 2 次**：过压故障；
  - **红灯连续闪烁 7 次**：位置误差超差报警。

## 四、拨码开关设定（SW1 ~ SW6）

ESS57P 采用 6 位 DIP 拨码开关设定滤波时间、电机旋转方向及微步细分精度：
- **SW1**：设定电机旋转方向。`ON` = CW（顺时针），`OFF` = CCW（逆时针）。
- **SW2 ~ SW5**：设定细分步数/圈（16 种固定细分）。
- **SW6**：设定位置指令平滑滤波时间。

## 五、典型控制接线原理图

### 1. 宽压信号输入接线（免外串电阻）
ESS57P 内部已集成宽压恒流电路，**PU+、DR+、EN+ 原生兼容 5V ~ 24V 控制电平**。无论是 5V 控制卡还是 24V PLC 直连，均**无需在信号回路中外串任何限流电阻**，接线极大简化！

### 2. 接线拓扑电路结构

```text
【差分控制信号接线（5V ~ 24V 均可直连）】
控制器 (Controller)                     ESS57P 驱动器
┌──────────────────┐                  ┌──────────────────┐
│  PULSE +         ├─────────────────►│ PU+ (免外接电阻) │
│  PULSE -         ├─────────────────►│ PU-              │
│  DIR +           ├─────────────────►│ DR+ (免外接电阻) │
│  DIR -           ├─────────────────►│ DR-              │
│  ENA +           ├─────────────────►│ EN+ (免外接电阻) │
│  ENA -           ├─────────────────►│ EN-              │
└──────────────────┘                  └──────────────────┘

【PLC 单端共阳极接线（24V 直连，无需外串电阻）】
PLC 外部电源 (24VDC)                    ESS57P 驱动器
+24V ─────────┬───────────────────────► PU+ (脉冲正)
              ├───────────────────────► DR+ (方向正)
              └───────────────────────► EN+ (使能正)
PLC 晶体管输出端 (NPN)
Y0 (PULSE)   ────────────────────────► PU- (脉冲负)
Y1 (DIR)     ────────────────────────► DR- (方向负)
Y2 (ENABLE)  ────────────────────────► EN- (使能负)

【ALM 报警输出端口接线 (OC门)】
              +24VDC ───┬──────────────────────────────┐
                        │                              │
                     [继电器线圈]                  [PLC 输入 DI]
                        ▲                              │
                   [续流二极管]                        │
                        │                              │
驱动器 AL+  ────────────┴──────────────────────────────┘
驱动器 AL-  ──────────────────────────────────────────► 0V (GND)
```
