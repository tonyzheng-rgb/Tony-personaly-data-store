# JSS86 一体化数字式闭环电机说明书

## 一、产品介绍

### 1. 概述
JSS86 是一款新型带通讯功能的电机驱动一体化混合伺服驱动系统。采用新一代 32 位 ARM 控制技术和闭环矢量控制技术，可以防止失步，保证加工精度；高速转矩衰减远低于传统开环驱动器，可以大幅提升步进电机的高速性能和力矩；采用基于负载的电流控制技术，有效降低电机温升，延长电机使用寿命；内置的位置到位和报警输出信号，方便上位机进行监测和控制；位置超差报警功能保证了加工设备的安全运行。

JSS86 是传统开环步进驱动的理想升级换代产品，并且可以替代部分传统交流伺服系统，价格仅为交流伺服系统的 50%。

### 2. 特点
* **高性能闭环控制**：采用先进 32 位 ARM 芯片及矢量闭环控制技术，默认工作在闭环模式彻底防止失步，同时支持开环模式；
* **高速大扭矩输出**：显著提高电机的输出力矩及高速运行速度，高速性能优异；
* **智能电流调整**：电流大小根据负载智能调节，降低电机温升，锁机电流及闭环峰值电流可调；
* **免增益调节**：适应各种机械负载状况（包括低刚性的皮带轮和滑轮等负载），不需要调整增益参数；
* **可设平滑滤波**：可设置位置指令平滑滤波时间，电机运行更平滑，振动更轻微，加减速动态性能显著提高；
* **零速静止锁定**：完成定位之后，具备无振动的零速静止锁定能力；
* **双脉冲控制**：支持单脉冲（脉冲+方向）和双脉冲输入，脉冲响应频率最高可达 200kHz；
* **丰富细分选择**：支持 15 种常用固定细分数（拨码开关设定），并支持上位机软件配置任意细分（200 ~ 65535 步/圈）；
* **Modbus 通信控制**：支持 RS232 串口上的 Modbus RTU 协议，可通过通信方式进行位置和速度控制，并实时监控电机运行状态（速度、位置偏差、母线电压、运行电流等）；
* **高压供电**：供电电压范围 DC +24V ~ 80V（推荐供电 DC +60V）；
* **完备故障保护**：具有过流、过压、位置超差等多种保护功能。

### 3. 典型应用
适合各种中大型自动化设备和仪器，例如：
* 工业机器人、数控机床、雕刻机、自动化立体仓库、纺织机械、特种工业缝纫机；
* 剥线机、打标机、切割机、激光照排机、绘图仪、自动装配设备等。
* 在用户期望大扭矩、低噪音、高速度、高可靠性的设备中应用效果特佳。

  * **闪烁 2 次**：母线过压故障；
  * **闪烁 5 次**：位置跟踪误差超差报警。

## 四、拨码开关设定

JSS86 采用 8 位 DIP 拨码开关设定控制模式、电机旋转方向、指令平滑滤波时间及步进细分精度：
* **SW1**：控制模式选择（开环 / 闭环）；
* **SW2**：电机旋转方向设定；
* **SW3 ~ SW4**：位置指令平滑滤波时间常数设定；
* **SW5 ~ SW8**：步进细分微步步数设定。

### 1. 控制模式选择（SW1）
| 拨码状态 | 控制模式 | 详细说明 |
| :---: | :---: | :--- |
| **SW1 = ON** | **开环控制模式** | 驱动器作为传统开环步进驱动运行，按开环设定电流输出 |
| **SW1 = OFF** | **闭环控制模式** | 驱动器工作在闭环矢量控制模式，绝对不丢步，智能调流（**出厂默认**） |

### 2. 电机旋转方向设定（SW2）
| 拨码状态 | 初始运行方向 | 详细说明 |
| :---: | :---: | :--- |
| **SW2 = ON** | **CW（顺时针）** | 初始正转方向为顺时针 |
| **SW2 = OFF** | **CCW（逆时针）** | 初始正转方向为逆时针 |

### 3. 指令平滑滤波时间设定（SW3 ~ SW4）
滤波时间常数越大，电机运行越平滑，加减速冲击越小，运转噪音更低，但指令跟随响应略有微小滞后。
| SW3 | SW4 | 滤波时间常数 (ms) | 详细说明 |
| :---: | :---: | :---: | :--- |
| **ON** | **ON** | **0 ms** | 关闭硬件滤波。**在此档位下可以通过 RS232 通信灵活修改内部滤波参数** |
| **OFF** | **ON** | **3 ms** | 轻度滤波，兼顾响应与平稳性 |
| **ON** | **OFF** | **15 ms** | 中度滤波，适合中等惯量负载 |
| **OFF** | **OFF** | **30 ms** | 强滤波，运行极为安静平滑，适合低速大惯量平稳运行 |

### 2. 输出信号（ALM 与 PEND）接口电路
* ALM+ / ALM- 及 PEND+ / PEND- 为光电隔离集电极开路（OC门）输出；
* 最高外接耐受电压：30VDC；
* 最大饱和输出电流：50mA。

```
                    +---------------------------+
                    |  JSS86 驱动器内部         |
                    |                           |
                    |       +--------+          |
                    |       |  光耦  |          |
                    |       | 发光管 |          |
                    |       +----+---+          |
                    |            |              |
                    |            v              |
                    |          |/   集电极      |
                    |   +------|  -----------> [ALM+ / PEND+]
                    |          |\>  发射极      |      |
                    |            |              |      | (外部负载)
                    |            +-----------> [ALM- / PEND-]
                    |                           |      |
                    +---------------------------+      v
                                                     [ 0V ]
```

> **注意**：当输出端驱动感性负载（如小型直流中间继电器）时，**必须在线圈两端反向并联续流二极管（例如 1N4007）**，否则断开瞬间的反向感应高压将击穿输出三极管！

## 七、JSS 步进伺服驱动器 MODBUS RTU 专用协议规范（RS232 通信）

> 本章对应原手册第七章通信专篇，通过板载 RS232 串口（支持与上位机 PC 或 PLC 串口通信）进行驱动器内部运行状态的实时在线监控与参数批量重构。

### 1. 通信基本规约
- **从站地址 (Slave ID)**：固定为 `01H`；
- **波特率 (Baud Rate)**：固定为 **38400 bps**；
- **字符帧格式**：`1+8+1`（1 位起始位，8 位数据位，1 位停止位，无奇偶校验位，即 **38400, 8-N-1**）；
- **通信间隔**：帧起始 STX 与帧结束 END 之间间隔最小为 3.5 个字符时间；
- **校验方式**：CRC-16（低字节在前，高字节在后）。

### 4. 关键读写指令报文示例

#### (1) 读取保持寄存器（03H）
读取 0x0005 起始的 2 个寄存器（原手册示例，假设 0x0005=1000、0x0006=45）：
- **主站请求**：`01 03 00 05 00 02 D4 0A`
- **从站正常响应**：`01 03 04 03 E8 00 2D BA 5E`（原手册示例：`03E8h` = 1000, `002Dh` = 45）

#### (2) 写单个保持寄存器（06H）
将滤波时间 512 ($0x0200$) 写入地址 `0x000D`：
- **主站发送**：`01 06 00 0D 02 00 19 69`
- **从站响应**：`01 06 00 0D 02 00 19 69`

#### (3) 批量写多个保持寄存器（10H）
将滤波时间 512 ($0x0200$) 写入 `0x000D`，同时将使能极性 1 ($0x0001$) 写入 `0x000E`：
- **主站发送**：`01 10 00 0D 00 02 04 02 00 00 01 F2 4E`
- **从站响应**：`01 10 00 0D 00 02 D0 0B`

#### (4) 异常错误应答报文
当收到非法功能码、非法寄存器地址或数据越界时，从站返回高位置 1 的异常功能码：
- **异常响应帧格式**：`[从站地址 01H] [CMD + 0x80] [异常码] [CRC16低] [CRC16高]`
- **异常码定义**：`01H`（非法功能码），`02H`（非法寄存器地址），`03H`（非法数据值），`04H`（从站设备执行故障 / CRC 校验出错）。
