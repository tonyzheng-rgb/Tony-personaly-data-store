## 0. 通用计算规则

```
含税价 = 未税价 × 税点
美金价 = 含税价 ÷ 汇率        （汇率 6.67，按当日中间价校准）
```

| 项 | 口径 |
|---|---|
| 默认输出 | 未税价，并注明档位 |
| 税点（按品类，以原始表表头为准，2026-11-02 已核对） | 伺服 ×1.10；步进/开关电源/杰斯特/昌盛/第四轴/常荣/拖链 ×1.13；翰祺/昌隆、丝杆导轨、通航 AST 段原表无税率，待确认 |
| NMRV 蜗轮减速机 | **已含税含运**，不再叠加 |
| 出口美金汇率 | 6.67（历史口径 6.7），报价当天按中间价校准并注明 |
| 闭环转矩系数 | 理论转矩 = 同规格开环 × 1.10（旧报价包规则，本次原表未见，待核） |
| 数量加价门槛（各表不一，无全公司统一规则） | 伺服、开关电源：100 台（套）以下 +5%（伺服 ASME1 除外）；杰斯特、第四轴：10 台（套）以下 +5 点；常荣：20 台以下 +5 点；其余按各自原表档位 |

> ✅ **税点已按原始表核对（2026-11-02）**：不存在「通用税点 ×1.10」——×1.10 只有金三士伺服一家（原表表头「未税价格，含税加10%」）。步进、电源、主轴（杰斯特/昌盛）、第四轴、常荣、拖链表头均为「含税加 13%」。报价时按品类取税点并在输出中写明。
