# 3A225 出口管制合规参考

> 数据截至 2026-10-09。法规与海关政策会更新，重大出口决策前请核实当期口径。

## 一、核心判定规则

中国《两用物项出口管制清单》**3A225 条款**：变频器同时满足以下三个条件即属于管制物项，**必须提前申请两用物项出口许可证**后方可报关出口：

1. 多相输出功率 **≥ 40 VA**
2. 工作频率 **≥ 600 Hz**
3. 频率控制精度 **< 0.2%**

三条件**同时满足**才触发。低于 600Hz 的常规工业变频器不在管制范围。

**本司产品适用结论：**
- 常荣 H100 / H300 系列（0–400Hz）→ **不受 3A225 管制**，可正常出口
- 0–1000Hz 产品 → 需按实际铭牌频率精度参数逐台核对三条件

## 二、时间线

| 时间 | 事件 |
|---|---|
| 2024-12 | 《两用物项出口管制条例》正式落地 |
| 2025 起 | 全国执法加严 |
| 2026-06 | 海关已具备主动识别 3A225 管制变频器的能力；福州木泰出口 0–600Hz 变频器无证被查为公开典型案例 |
| 2026-07-28 | 美国 FCC 管制生效，仅针对联网型并网光伏/储能逆变器，**工业电机调速变频器不受限制** |
| 2027-01 | IEC 61800-5-2:2026 正式执行，出口 IEC 成员国的工业变频器/伺服驱动需通过 SIL2 / PLd 功能安全验证 |

## 三、海关排查机制

1. **参数自动扫描**：报关单申报参数中输出频率 ≥ 600Hz 自动标红，触发风控
2. **HS 编码热点**：8504409999（静止变流器兜底编码）属两用物项热点管控税号，系统自动高风险布控，查验率 30%–50%
3. **现场查验**：必核对铭牌、说明书参数。参数与申报不一致 = 申报不实 + 隐瞒两用物项双重违规，追溯期 3 年

## 四、合规操作指引

1. **产品尚未报关**：向商务部 `jingwaizixun@mofcom.gov.cn` 提交 3A225 出口许可证申请，审批周期约 20 个工作日
2. **已出口且存在申报不实记录**：可主动向属地海关 / 商务厅**主动披露**，配合整改可从轻或免予处罚
3. **报关原则**：报关单参数必须与铭牌、说明书、实际产品完全一致，**不得低报参数隐瞒管制属性**

## 五、禁止事项

只提供完全合规方案。以下一律不做、也不提供变通：

- ❌ 伪报、低报频率参数以规避管制
- ❌ 瞒报两用物项属性
- ❌ 变造铭牌、说明书
- ❌ 指导客户如何规避海关识别

遇到"客户要求这样报"的情况，明确指出违规后果（申报不实 + 隐瞒两用物项双重违规，追溯 3 年），并给出合规路径（提前申请许可证 / 主动披露整改）。
