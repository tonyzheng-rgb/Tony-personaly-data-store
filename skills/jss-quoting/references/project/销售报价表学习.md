# 销售报价表（已学习）

## 报价表位置
- 主文件：`新对外销售价2026.3.30 V5.xls`
- 版本：新对外销售价 2026.3.30 V5
- 报价单标题：金三士电机报价一览表（国产普通轴承），未税价，含税加13%

## 覆盖产品线（4大类）
1. **步进电机及驱动器** — 86HS/57HS/42HS 开环、42HSE/57HSE/60HSE/86HSE 闭环、DM/HSS/HBS 驱动器、电机+驱动器套装
2. **无刷电机 (BLDC)** — 36YBL/42YBL/57BLY/57BL/60BL/80BL/86BL/110BL/130BL、67BL/78BL
3. **杭州通航伺服电机** — 40/60/80/110/130/180 框架，磁编/光编绝对值
4. **SZXHY 开关电源** — 12V/24V/5V/36V/48V/60V/80V 全功率段

## 用户问价规则（已确认 2026-10-11）
- **默认未税价**，含税价 = 未税价 × 1.13
- **步进电机默认报中批量价**（50-200台档位）
- 用户问价时**不带客户场景**，直接按价格表报

## 重要价格逻辑
- 步进电机：分批量/小批/零售三档，按数量分档
- 无刷电机：分<20台/20-99台/100-1000台三档，税前税后两套
- 伺服电机：单一定价；配多圈绝对值编码器 +加价、加刹车 +加价
- 开关电源：100台以下在此价格基础上再加 5 个点，不含运费
- 闭环电机可选项：定制国产轴承、塑料后罩、编码器线延长（5米内 +5元/米，超出 +7元/米）
- 爆品定义：图纸固定，不能任何更改

## 工作方式
- 用户问价格时，先读取主文件 Excel，定位具体型号
- 如文件读取失败或数据不完整，告诉用户并建议提供完整型号信息
- 报价时主动说明"未税价"和价格档位
- 跨品类查询时，先确认客户在问哪类产品（步进/无刷/伺服/电源）
