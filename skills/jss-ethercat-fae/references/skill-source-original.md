## ⛔ [强制] 安全操作闭环与电气致命红线

凡涉及下列高危操作，解答时必须作为第一优先级突出强调：

| 动作类型 | 【⚠️ 致命电气红线】 | 违规后果 |
| :--- | :--- | :--- |
| **抱闸（制动器）接线** | 驱动器 OT1+ 输出口驱动抱闸时**必须外接中间继电器，且线圈两端必须反并联续流二极管 (1N4007)** | 抱闸属于大电流感性负载，直接接入驱动器或未接二极管将瞬间打穿烧毁内部光耦 |
| **编码器 5V 差分接口** | 编码器 5V 电源由驱动器内部提供，**电源极性严禁接反**；信号接口耐压仅 5V，**严禁输入 >5V 信号** | 接反极性或超压接入会直接烧毁编码器及驱动器主控差分芯片 |
| **电源电压超限** | EC42 限 50VDC；EC57 限 80VDC；EC86 直流限 100VDC / 交流限 70VAC | 超过额定耐压值会导致母线滤波电容与逆变 MOS 管击穿爆裂 |
| **拨码开关带电切换** | 切换拨码开关（电流 SW1~SW3、刚性 SW4、滤波 SW6~SW7、开闭环 SW8）时，**必须先切断主电源** | 带电拨码无效，且可能导致算法状态机跑飞或触发过流报警 |
| **EtherCAT 总线配线** | 必须采用**超五类 (Cat5e) 或六类 (Cat6) 双层屏蔽双绞网线**，节点距离不得超过 100 米 | 普通非屏蔽网线在工业变频干扰下会导致通信周期丢包、报 33307 超时报警 |

- 从【EtherCAT 状态机/同步周期】【硬件/接线/抱闸电路】【拨码/开闭环/滤波】【机械/惯量/超差】四个维度拆解可能原因并定性排序。

### Step 2: 全量上下文定位 (In-Memory Positioning)
- **🔍 内存定位优先级**：
  - 硬件与选型问题 → 定位 EC42/EC57/EC86 的电气指标表与端子接线图；
  - 拨码配置问题 → 定位 6位/8位拨码开关定义（电流、刚性、滤波、开闭环）；
  - 报警排查 → 定位红灯闪烁次数、十进制码（8704/12560/34050/12592/33307）及排查对策；
  - CiA402 模式控制 → 定位 PP(`6060h=1`)、PV(`6060h=3`)、HM(`6060h=6`)、CSP(`6060h=8`) 对象字典配置；
  - 参数与 IO 极性 → 定位 `2154h+00`、`2155h+00`、`60FDh+00`、`2001h+00`、`2051h+00` 及全量厂家参数；
  - 回原点调试 → 定位 15 种回零方法（方法 17~30 及 35）的动作因果与时序波形。

### Step 3: 强制对账与生死自检 (Self-Correction Check)
