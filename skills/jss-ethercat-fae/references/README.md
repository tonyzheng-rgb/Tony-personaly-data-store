## 3. 全系指示灯状态与故障代码速查

| 指示灯状态 | 十进制代码 | 十六进制代码 | 故障名称 | 排查要点 |
| :--- | :---: | :---: | :--- | :--- |
| **蓝灯常亮** | - | - | **驱动器正常** | 正常运行状态 |
| **红灯闪 1 下** | **8704** | **`0x2200`** | **过流故障** | 电机相间短路、对地短路、绝缘破损或电流过大 |
| **红灯闪 2 下** | **12560** | **`0x3110`** | **过压故障** | 母线电压超限（EC57 > 80V, EC86 > 100V），急停反电势泵升，增大减速时间 |
| **红灯闪 3 下** | - | - | **欠压故障** | 母线电压低于下限（< 15VDC / 24VDC），检查供电电源及接线 |
| **红灯闪 7 下** | **34050** | **`0x8502`** | **编码器超差故障** | 电机失步、卡阻、编码器电缆脱落或相序接反 |
| **红灯闪 9 下** | **12592** | **`0x3130`** | **运放故障** | 内部电流采样运放硬件异常，断电重启，若仍异常返厂检修 |
| **网口灯不闪** | **33307** | **`0x821B`** | **SM 配置超时 / 通讯超时报警** | EtherCAT 同步管理器（SyncManager）配置超时或网络中断，检查网线、主站周期及 XML 文件 |
