> **常州市金三士机电有限公司**

## 一、简介与产品特性

### 1. 概述
EC57 是常州市金三士机电有限公司最新研发的 **EtherCAT 总线型闭环步进驱动器**，采用最新 32 位 DSP 数字信号处理技术。驱动器控制算法融合了先进的变电流技术与矢量变频技术，驱动器自身发热极小，电机运行超低振动、超低噪音、运转平稳。用户可通过总线或拨码设置额定电流范围内的任意电流值，能够满足大多数自动化工业场合的高精度定位需要。驱动器内部集成了参数上电自动整定功能，能够针对不同电机自动生成最优运行参数，最大限度发挥步进电机的力矩与速度潜能。

### 2. 特点
* **全新 32 位 DSP 技术**：高速算法内核，实时处理 EtherCAT 周期同步通信；
* **超低振动与噪声**：矢量电流环控制，低速无共振区；
* **参数上电自动整定**：针对所匹配电机的电阻电感特性自动整定 PID 控制环；
* **变电流发热控制**：根据负载转矩需求动态调整电流，电机发热大幅降低；
* **多电机兼容**：可驱动 4、6、8 线两相混合式步进电机；
* **光隔离差分接口**：工业级光电隔离输入输出，高抗干扰能力；
* **宽电流选择**：峰值电流可在 0.1A ~ 5.6A 之间灵活配置；
* **全方位硬件防护**：具有过压、欠压、过流、编码器位置超差、运放异常及通讯超时等多重报警保护。

### 3. 应用领域
适合各种 EtherCAT 通讯协议的中小型自动化设备和仪器，例如：数控机床、雕刻机、打标机、切割机、激光照排、绘图仪、自动装配设备、半导体封装测试机、3C 自动化产线等。在用户期望高速度、高精度、低噪音、多轴网络化协同的设备中应用效果最佳。

## 三、驱动器接口和接线介绍

### 1. 电源与电机绕组端子（6Pin）
| 名称 | 管脚 | 功能说明 |
| :---: | :---: | :--- |
| **VDC** | 1 | 直流电源正极，供电电压范围：直流 24 ~ 80Vdc，推荐 24Vdc 或 36Vdc 工作 |
| **GND** | 2 | 直流电源地（0V） |
| **A+** | 3 | 两相步进电机 A+ 相绕组接口 |
| **A-/U** | 4 | 两相步进电机 A- 相绕组接口（或三相电机的 U 相） |
| **B+/V** | 5 | 两相步进电机 B+ 相绕组接口（或三相电机的 V 相） |
| **B-/W** | 6 | 两相步进电机 B- 相绕组接口（或三相电机的 W 相） |

> **配线要求**：VDC、GND、A+、A-、B+、B- 端子配线线径 $\ge 0.3\text{ mm}^2$ (AWG15-22)。建议直流电源输入经过噪声滤波器供电，提供系统抗干扰性。

### 2. 编码器接口（8Pin，开环步进模式下不接）
| 名称 | 管脚 | 功能说明 |
| :---: | :---: | :--- |
| **EZ-** | 1 | 编码器 Z 信号差分输入负端（开环步进不接） |
| **EZ+** | 2 | 编码器 Z 信号差分输入正端（开环步进不接） |
| **EB-** | 3 | 编码器 B 信号差分输入负端（开环步进不接） |
| **EB+** | 4 | 编码器 B 信号差分输入正端（开环步进不接） |
| **EA-** | 5 | 编码器 A 信号差分输入负端（开环步进不接） |
| **EA+** | 6 | 编码器 A 信号差分输入正端（开环步进不接） |
| **GND** | 7 | 驱动器提供给电机编码器的直流参考地 |
| **5V** | 8 | 驱动器提供给电机编码器的直流 +5V 电源，输出电流能力 100mA |

> **⚠️ 编码器接口致命红线**：
> 1. 编码器电源由驱动器内部提供 5V，**电源线极性绝对不可接反**，否则会瞬间烧毁电机编码器或驱动器；
> 2. 编码器信号必须为 5V 差分信号，接口耐压仅为 5V，**严禁接入超过 5V 的信号电平**；
> 3. 编码器引线必须采用双绞屏蔽线，长度建议不超过 3 米，且必须远离电机动力线。

### 3. 控制信号端口（8Pin）
| 名称 | 管脚 | 详细功能说明 | 对应 CiA402 对象映射 |
| :---: | :---: | :--- | :--- |
| **IN0-** | 1 | 数字输入 0 信号端，兼容电平 4.5 ~ 28VDC | 默认功能：**负限位 (NOT)**（对应 `0x60FD` 的 Bit0） |
| **IN1-** | 2 | 数字输入 1 信号端，兼容电平 4.5 ~ 28VDC | 默认功能：**正限位 (POT)**（对应 `0x60FD` 的 Bit1） |
| **IN2-** | 3 | 数字输入 2 信号端，兼容电平 4.5 ~ 28VDC | 默认功能：**原点开关 (HOME)**（对应 `0x60FD` 的 Bit2） |
| **IN3-** | 4 | 数字输入 3 信号端，兼容电平 4.5 ~ 28VDC | 预留通用数字输入 |
| **IN+** | 5 | 数字输入信号公共端，兼容电平 4.5 ~ 28VDC | 输入光耦共阳端，接外部 +24V 电源正极 |
| **OT-** | 6 | 数字输出信号 0 负端 | 最大上拉电压 24Vdc，上拉电阻 2kΩ，最大输出电流 100mA |
| **OT0+** | 7 | 数字输出信号 0 正端 | 默认功能：**报警输出 (ALM)** |
| **OT1+** | 8 | 数字输出信号 1 正端 | 默认功能：**到位输出 / 刹车抱闸输出** |

### 4. 刹车抱闸接线原理图（OT1+ / OT-）

```text
               外部 24V 供电电源
              ┌─────────────────┐
              │ +             - │
              └─┬─────────────┬─┘
                │             │
                │     ┌───────┴──────┐
                │     │   继电器     │
                │     │    线圈      │
                │     └───────┬──────┘
                │             │
                │    ┌────────┴────────┐
                │    │   反并联续流    │
                │    │    二极管       │
                │    └────────┬────────┘
                │             │
   驱动器 OT-  ─┴─────────────┤
                              │
   驱动器 OT1+ ───────────────┘
```

> **⚠️ 输出端安全红线**：
> 1. 外部电源由用户提供，电源极性接反会烧毁驱动器；
> 2. 输出为 OC 门形式，最大允许电流 50mA，最大电压 25V，**严禁将输出端直接短接在电源两端**；
> 3. 当驱动抱闸继电器等感性负载时，**必须在负载线圈两端反向并联续流二极管**（二极管正极接 OT1+，负极接 24V+），否则断开时感应出的几百伏反峰高压会瞬间击穿驱动器内部输出三极管！

### 5. EtherCAT 总线通讯接口（双 RJ45）
- **EtherCAT IN（上端口）**：连接主站或上一级从站 OUT 口。
- **EtherCAT OUT（下端口）**：连接下一级从站 IN 口。

## 四、拨码开关定义（SW1 ~ SW8）

EC57 采用 8 位 DIP 拨码开关进行峰值电流、刚性、方向、滤波常数及开闭环模式硬件设定：

### 1. 峰值电流设定表（SW1 ~ SW3）
| 峰值电流 | SW1 | SW2 | SW3 |
| :---: | :---: | :---: | :---: |
| **1.4A** | ON | ON | ON |
| **2.1A** | OFF | ON | ON |
| **2.7A** | ON | OFF | ON |
| **3.2A** | OFF | OFF | ON |
| **3.8A** | ON | ON | OFF |
| **4.3A** | OFF | ON | OFF |
| **4.9A** | ON | OFF | OFF |
| **5.6A** | OFF | OFF | OFF |

### 2. 模式与方向选择（SW4 ~ SW5）
- **SW4：模式选择（刚性设置）**
  - `ON`：刚性大（响应极快，适用于高刚性直驱、高动态丝杠机构）；
  - `OFF`：刚性小（运行柔和，适用于皮带传动、小惯量滑轮，抑制振动）。
- **SW5：方向选择**
  - `ON`：正转；
  - `OFF`：反转。

### 3. 平滑滤波时间常数设定（SW6 ~ SW7）
| 滤波时间常数 | SW6 | SW7 | 适用场景说明 |
| :---: | :---: | :---: | :--- |
| **0 ms (无滤波)** | ON | ON | 适合外部轨迹插补周期极短（如 1ms 周期同步 CSP 模式） |
| **2 ms** | OFF | ON | 抑制高频抖动，平滑运动轨迹 |
| **12 ms** | ON | OFF | 显著减少加减速瞬间机械冲击 |
| **25 ms** | OFF | OFF | 极大柔化加速度跳变，运行最安静平稳 |

### 4. 开闭环模式选择（SW8）
- **SW8：开闭环选择**
  - `ON`：开环步进模式（无需编码器反馈即可运转）；
  - `OFF`：闭环伺服模式（必须连接编码器，抗失步保护生效）。

## 六、CiA 402 回原点方法时序波形与执行算法（Homing Methods）

EC57 完整支持 CiA 402 标准规定的 15 种回原点方法：

### 1. 方法 17：反向寻找原点（负限位下降沿为原点）
- **减速点**：负限位开关 (NOT)；**原点**：负限位下降沿。
- **动作过程**：
  - 若启动时 NOT=0：以高速（`6099h-01`）反向运行，遇到负限位信号上升沿后减速反向，以低速（`6099h-02`）正向运行，脱离负限位开关瞬间（NOT 下降沿）停机锁死为零点；
  - 若启动时 NOT=1：直接以低速正向运行，遇到 NOT 下降沿立即停机。

### 2. 方法 18：正向寻找原点（正限位下降沿为原点）
- **减速点**：正限位开关 (POT)；**原点**：正限位下降沿。
- **动作过程**：
  - 启动时 POT=0：高速正向运行，撞到正限位上升沿后减速反向，低速反向脱离正限位开关（POT 下降沿）停机；
  - 启动时 POT=1：直接以低速反向运行，遇到 POT 下降沿停机。

### 3. 方法 19 与 20：正向寻找原点（仅原点开关 HOME 模式）
- **减速点**：原点开关 HOME；
- **方法 19 原点**：HOME 信号的左侧边缘（上升沿/下降沿）；
- **方法 20 原点**：HOME 信号的右侧边缘。

### 4. 方法 21 与 22：反向寻找原点（仅原点开关 HOME 模式）
- **减速点**：原点开关 HOME；
- **方法 21**：反向高速寻 HOME，以 HOME 右侧边缘作为零点；
- **方法 22**：反向高速寻 HOME，以 HOME 左侧边缘作为零点。

### 5. 方法 23 ~ 26：正向原点 + 正限位防撞保护模式
- **方法 23 / 24**：正向寻找原点开关 HOME。若运行中先遇到 HOME，以原点信号边缘定位；若未遇到 HOME 而先撞到正限位开关 POT，驱动器自动减速并反向高速折返，脱开限位后再去精确定位 HOME 信号；
- **方法 25 / 26**：原点信号位于限位开关内侧的双重判定逻辑。

### 6. 方法 27 ~ 30：反向原点 + 负限位防撞保护模式
- **方法 27 / 28**：反向寻找原点开关 HOME。若运行途中先撞到负限位开关 NOT，自动反向高速回折，再捕获原点开关边缘；
- **方法 29 / 30**：负限位与原点重叠区的高可靠性回零算法。

### 7. 方法 35：当前位置设为原点 (Set Current Position as Zero)
- **动作流程**：无任何轴物理运动。主站设置 `6098h = 35` 触发后，驱动器立即将当前编码器实际位置（`6064h`）清零或加载原点偏移量（`607Ch`），状态字 `6041h` 立即置位回零完成。
