## 二、关键特性与架构差异深度比对

### 1. 霍尔相位角拨码极性陷阱（极为关键！）
- **低压驱动器系列 (BLDC-150L, BLDC300-6012A, BLDC-750L)**：
  - `SW1 = ON`：霍尔相位角为 **120° / 240°**（市面 95% 标准无刷电机）；
  - `SW1 = OFF`：霍尔相位角为 **60° / 300°**。
- **高压驱动器系列 (BLDC-750H)**：
  - `SW1 = ON`：霍尔相位角为 **60° / 300°**！
  - `SW1 = OFF`：霍尔相位角为 **120° / 240°**！
  - ⚠️ **FAE 警示**：高低压系列的 SW1 逻辑完全相反，更换机型时务必检查拨码，切勿照搬经验！

### 2. RS485 通讯协议体系断代与指令分流
- **体系 A：低压 485 系列 (`BLDC300-6012A-485` 与 `BLDC-750L-485`)**：
  - 寄存器地址空间：`0x8000` 系列（如 `0x8000` 控制字、`0x8005` 速度设定、`0x8007` 站号地址、`0x8018` 实际转速、`0x8019` 运行电流等）；
  - 数据存储格式：**小端模式 (Little-Endian，低字节在前，高字节在后)**；
  - 功能码：`03H` 连续读寄存器，`06H` 单写寄存器。
- **体系 B：高压 485 系列 (`BLDC-750H`)**：
  - 采用完全独立的功能码与命令字架构，大端模式：
    - `03H`：读驱动器状态（返回 1 字节状态位图：`01H` 欠压、`02H` 过压、`04H` 过流、`08H` 过热、`10H` 停止、`20H` 正转、`40H` 反转）；
    - `04H`：读参数（`0x07` 控制模式、`0x08` 从机地址、`0x09` 母线电压、`0x0A` 输出电流）；
    - `06H`：电机运行控制（`0x00` 开环PWM占空比、`0x01` 闭环转速、`0x02` 启停、`0x03` 刹车制动、`0x04` 方向、`0x05` 启动加速度、`0x06` 485通信波特率）；
    - `10H`：配置参数（`0x07` 开闭环模式、`0x08` 从机地址）。
  - ⚠️ **FAE 警示**：绝不可混淆体系 A 与体系 B 的通讯帧，否则将直接导致从机无应答或报 CRC 校验错误！

### 3. BLDC-750L V1.2 与 V2.1 固件版本演进比对
- **电压保护阈值**：
  - V1.2：欠压保护点约 18V，过压保护点约 60V。
  - V2.1：拓宽工作边界，欠压保护点放宽至 `< 15V`，过压保护点放宽至 `> 62V`。
- **SW1 拨码定义**：
  - V1.2：`SW1` 为“有感 / 无感”模式选择拨码（ON=有感，OFF=无感）。
  - V2.1：`SW1` 重新定义为霍尔相位角拨码（ON=120°，OFF=60°）。无感模式通过“拔掉霍尔排线后重新上电”由固件自动识别进入。
- **ENBL 使能逻辑反转（重大踩坑点！）**：
  - **V1.2 版**：`ENBL` 悬空不接 = 使能运行（联机）；`ENBL` 接 GND = 停机（脱机，红灯常亮）。
  - **V2.1 版**：`ENBL` 接 GND = 使能运行（联机）；`ENBL` 悬空不接 = 停机（脱机，红灯常亮）！
  - ⚠️ **FAE 警示**：老设备现场用 V2.1 替换 V1.2 时，若沿用原本悬空的 ENBL 接线，电机将完全不动且红灯常亮！必须将 ENBL 引脚接入 GND 才能启动！
- **低速死区限制（V2.1 新增保护）**：
  - 开环模式下，输入信号占空比 `< 16%` 时电机不启动，`≥ 16%` 时直接输出 16% 占空比启动；
  - 闭环模式下，设定转速 `< 150 RPM` 时电机不启动，`≥ 150 RPM` 时电机按设定值平稳起步，杜绝低速堵转震颤与发热。
