## 一、主要特点与产品概述

### 1. 主要特点
* **有感/无感双模支持**：支持三相有感（霍尔）及无感无刷直流电机，通过硬件拨码即可一键切换；
* **低速平稳大扭矩**：支持占空比开环调速，低速力矩充沛，运转平稳；
* **双霍尔角度适配**：支持 60°/300° 以及 120°/240° 两种霍尔传感器安装角度；
* **多元调速方式**：自带 RV 电位器，支持外接 0 ~ 5V 模拟电压、PWM 脉冲信号（150Hz ~ 3kHz，频率或占空比调速）、外接 10kΩ 电位器；
* **完备控制接口**：具备 ENBL（使能）、F/R（方向）、BRK（刹车制动）信号控制端；
* **反馈信号输出**：具备测速脉冲输出端（SP）与硬件报警信号输出端（ALM）；
* **工业级强劲散热**：采用**强制风冷散热设计**，支持连续重载工作；
* **全方位硬件防护**：具备启动过流、运行过流、过压、欠压、堵转、换相故障及芯片过温等多重防护。

### 2. 产品概述
BLDC-750L 无刷直流电机驱动器是针对于小功率电机拖动领域的高性能产品。采用超大规模硬件集成电路，具有优异的抗干扰和快速响应能力。适合驱动峰值电流在 17A 以下、电源电压 DC 18V ~ 60V、功率在 750W 以内的任何一款低压三相无刷直流电机。

广泛应用于纺织机械、医疗器械、智能物流、食品加工、电动工具、园林自动化等工业控制领域。

### 3. 功能概述
1. **方波有霍尔速度开环运行**；
2. **方波无霍尔速度开环运行**。
* **出厂默认设置**：方波驱动、120° 霍尔角度、开环运行模式。可通过拨码开关自主选择。

## 四、拨码开关设定（SW1 ~ SW3）

BLDC-750L V1.2 版板载 3 位 DIP 拨码开关，具备独特的**有感/无感工作模式切换**功能：

| 拨码开关 | 拨码位状态 | 设定功能 | 功能说明与适用工况 |
| :---: | :---: | :--- | :--- |
| **SW1** | **ON** | **有感运行模式** | 必须连接电机霍尔传感器，有感方波开环驱动（**出厂默认**） |
| | **OFF** | **无感运行模式** | 无需连接霍尔信号线，反电势无感开环启动运行 |
| **SW2** | **ON** | **120° / 240° 霍尔布置** | 适配 120° 或 240° 电机霍尔角度（**出厂默认**） |
| | **OFF** | **60° / 300° 霍尔布置** | 适配 60° 或 300° 电机霍尔角度 |
| **SW3** | **ON** | **AVI 外部调速** | 由外部 AVI 端口（0~5V 或 PWM 信号）调节转速 |
| | **OFF** | **RV 内部调速** | 由板载 RV 电位器调节转速（**出厂默认**） |

> ⚠️ 修改拨码开关必须在断电后进行，上电后更改无效！

## 五、功能说明与调速测速算法

### 1. 调速方式选择（AVI 端口）
* **外接电位器调速**：电位器两端分别接 **GND** 和 **+5V (REF+)**，滑动端接 **AVI**（推荐阻值 10kΩ）；
* **模拟电压（0 ~ 5V）调速**：模拟电压正端接 **AVI**，负端接 **GND**；
* **PWM 脉冲调速**：PWM 信号正接 **AVI**，负接 **GND**，频率范围 $150\text{ Hz} \sim 3\text{ kHz}$。

### 2. 刹车制动（BRK 端子）
* **BRK 接 GND**：电机刹车停止运行；
* **BRK 悬空不接**：电机允许正常运转。（刹车制动力度可根据要求另行调整）。

### 3. 电机测速信号输出（SP 端子）
$$\text{电机转速 (RPM)} = \frac{F}{N} \times 60$$
* $F$：测速端子实际输出脉冲频率（Hz）；$N$：电机极对数。
* **计算示例**：4 对极电机（8极），当 SP 输出信号为 $200\text{ Hz}$ 时，电机转速为 $200 \div 4 \times 60 = 3000\text{ RPM}$。

### 4. 报警输出信号（ALM 端子）
* **正常工作状态**：输出 5V 高电平（相对于 GND）；
* **处于报警状态**：输出 5V 高电平（相对于 GND）。

## 六、安全操作规程与常见故障 FAQ

### 1. 安全注意事项
1. **断电接线**：切勿带电接线；
2. **三相相序一致**：U/V/W 必须与 HU/HV/HW 严格一致；
3. **霍尔电压核对**：REF+ 默认为 5V，若电机霍尔为特殊电压范围需提前联系厂家；
4. **PWM 最低频率**：AVI 端口采用 PWM 信号时，频率不得低于 100Hz；
5. **风道保持畅通**：驱动器为强制风冷散热，安装时必须保留足够的空气流通间隙，严禁堵塞风道或风扇进风口。

### 2. 常见问题排查解答（FAQ）
1. **Q: 如何尽快上手使用该驱动器？**
   * **A**: 正确接好电源、电机绕组和霍尔信号线，SW3 拨至 OFF（使用 RV 电位器），利用板载电位器缓慢顺时针加速，电机平稳旋转后再依次测试使能、方向及刹车功能。
2. **Q: 电源正负极接反有何后果？**
   * **A**: 会立即烧毁驱动器。
3. **Q: 上位控制信号输入电压极限？**
   * **A**: 调速信号最高电压为 5V，超压会导致驱动器烧毁。
4. **Q: 上电后修改拨码开关设置是否有效？**
   * **A**: 上电前更改有效；上电后更改无效，需断电后重新设置。
5. **Q: 外壳发热正常吗？**
   * **A**: 正常。常温下长时间工作外壳不超过 70℃ 不会对性能产生影响。
6. **Q: 电机不转且抖动？**
   * **A**: 相线与霍尔线线序有错误，请核对说明书重新对齐相序。
7. **Q: 用此驱动器，能否将我的电机转速调到 6000？**
   * **A**: 无刷电机的最高转速是由电机本身的参数决定的，驱动器能将电机转速控制在 0 至最高速。
8. **Q: 已经有电机，购买此驱动器后如何接线？**
   * **A**: 必须先确定电机的相线和霍尔线定义后才能接线，如不确定，需向电机厂家询问。不正确的接线会导致驱动器损坏。
9. **Q: 关于正反转切换的延时问题。**
   * **A**: 为避免在电机高速运行时突然换向，对电机及机械设备的巨大冲击，当 F/R 端接收到换向信号，驱动器先让电机减速直到停止，停止约 1s 后，电机改变转向，提速至设定转速。
