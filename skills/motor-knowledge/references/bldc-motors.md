# 无刷直流电机（BLDC）原理

## 结构

- 定子三相绕组，转子永磁。内转子转速高、惯量小；外转子转矩大、多见于云台和风机。极对数决定电角与机械角的比例：电角等于机械角乘以极对数，换相频率随极对数和转速上升。

- 位置反馈三种：霍尔（三个开关量，60 度或 120 度电角度布置）、编码器、无感（测反电动势）。霍尔相位角拨码必须与电机实际布置一致，金三士低压与高压驱动的 SW1 逻辑互反，是高频踩坑点（细节查 jss_bldc_fae）。

## 六步换相（梯形波控制）

- 每个电周期分六步，任意时刻两相导通一相悬空，转矩脉动约百分之十几。悬空相的反电动势过零点可用于无感换相定位。

- 相序与霍尔序必须对应：三相线序、霍尔线序任一接错，典型表现是抖动不转、反转、啸叫发热或报警。排查时按说明书的组合表逐项核对，不要凭颜色猜。

## FOC（磁场定向控制）

- 把三相电流变换到转子坐标系，分别控制转矩分量（Iq）和励磁分量（Id，常设为零），转矩平滑、噪声低、效率高，低速大转矩可控。伺服和高端无刷驱动本质都是 FOC 加位置速度环。

- FOC 需要准确的转子角度（编码器或观测器），无感 FOC 靠反电动势或高频注入估算角度，零速和极低速最难，这也是无感方案带载启动失败、低速抖动的原理根源。

## 关键参数

- Kv 是转速常数（每伏特空载转速），Kv 高的电机转速高、转矩常数低；转矩常数 Kt 与 Kv 互为倒数关系（SI 单位下数值相等）。选型时用最高转速定电压：母线电压要高于该转速下的反电动势并留电流调节裕量。

- 额定电流决定连续转矩，峰值电流决定短时过载；驱动器电流规格小于电机额定值时电机会被限流，转矩达不到铭牌。

## 调速方式

- 常见电位器、0 到 5V 或 0 到 10V 模拟量、PWM 占空比、总线（RS485 Modbus）给定。开环调速时转速随负载变化，闭环（霍尔或编码器反馈）才能稳速；金三士各型号的开闭环拨码与调速端口接法查 jss_bldc_fae 对应专篇，两套 Modbus 寄存器体系（低压与高压）严禁混用。

## 常见故障的原理

- 上电抖动不转：相序或霍尔序错、相位角拨码错、缺相（端子虚接）。

- 启动失败但手推能转：无感启动参数与负载惯量不匹配，或启动电流不足。

- 高速发热啸叫：换相提前角或驱动频率不匹配、轴承问题、电流过大。先区分电气噪声（随转速变调）与机械噪声（固定频段）。
