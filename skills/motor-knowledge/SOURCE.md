# Source and note (2026-11-02)

Written by Muse at Tony's request for motor-principle knowledge (stepper, BLDC, servo). A GitHub survey on 2026-11-02 found no credible installable SKILL.md package dedicated to motor principles, selection or troubleshooting, so this skill was authored from general engineering knowledge instead of copying a third-party package.

- Content is principle-level and deliberately contains no JSS product parameters; product data routes to the JSS FAE skills and driver manual collections listed in SKILL.md.
- Open references for deeper reading: SimpleFOC documentation (MIT) and ODrive official documentation, linked in SKILL.md; no text was copied from them.
- Treat numeric rules of thumb in the references as engineering heuristics, and verify against the specific product manual before acting on them.
